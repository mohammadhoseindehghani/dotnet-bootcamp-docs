# جلسهٔ دوم · محاسبه، تصمیم و تکرار

<div class="lesson-intro">تاریخ برگزاری: <bdi dir="ltr">1405/07/28</bdi><br>با داده‌هایی که از جلسهٔ قبل می‌شناسیم محاسبه می‌کنیم، تصمیم می‌گیریم و دستورها را تکرار می‌کنیم.</div>

## هدف‌های جلسه

- استفاده از عملگرهای حسابی، مقایسه‌ای، انتساب و منطقی.
- انجام محاسبات ساده با `Math` و کار مقدماتی با متن.
- انتخاب مسیر اجرا با `if`، `else` و دستور `switch`.
- تکرار دستورها با `while`، `do while` و `for`.

**پیش‌نیاز:** متغیر، نوع داده، تبدیل نوع و دریافت ورودی از [جلسهٔ اول](session-01.md). هر مثال این صفحه را جداگانه در `Program.cs` اجرا کن. در مثال‌های ورودی عددی، فرض بر وارد کردن عدد صحیح معتبر است.

## ۱. عملگرهای حسابی

عملگر روی مقدارها کاری انجام می‌دهد؛ مثلاً `+` دو عدد را جمع می‌کند.

| عملگر | کاربرد | نتیجهٔ مثال |
| --- | --- | --- |
| `+` | جمع | `7 + 3` برابر `10` |
| `-` | تفریق | `7 - 3` برابر `4` |
| `*` | ضرب | `7 * 3` برابر `21` |
| `/` | تقسیم | `7 / 3` برابر `2` |
| `%` | باقی‌ماندهٔ تقسیم | `7 % 3` برابر `1` |

### تقسیم صحیح و اعشاری

وقتی هر دو طرف تقسیم عدد صحیح باشند، نتیجه هم صحیح است و بخش اعشاری حذف می‌شود. حتی اگر نتیجه را در `double` بریزیم، تقسیم قبلاً انجام شده است:

```csharp
int first = 7;
int second = 2;

double wrongAverage = first / second;
double decimalResult = (double)first / second;

Console.WriteLine(wrongAverage);  // 3
Console.WriteLine(decimalResult); // 3.5
```

در محاسبهٔ دوم، قبل از تقسیم، `first` به `double` تبدیل شده است. نوشتن `7.0 / 2` هم نتیجهٔ اعشاری می‌دهد. در تقسیم صحیح، مخرج صفر باعث خطا می‌شود؛ در مثال‌های تقسیم، مخرج باید غیرصفر باشد.

### ترتیب انجام محاسبات

ضرب، تقسیم و باقی‌مانده قبل از جمع و تفریق انجام می‌شوند. پرانتز کمک می‌کند ترتیب دلخواه روشن باشد.

```csharp
Console.WriteLine(2 + 3 * 4);   // 14
Console.WriteLine((2 + 3) * 4); // 20
Console.WriteLine(10 % 2);     // 0
```

باقی‌ماندهٔ تقسیم بر ۲ برای عدد زوج صفر است. از این نکته در شرط‌ها استفاده می‌کنیم.

## ۲. انتساب و تغییر مقدار

```csharp
int score = 10;
score += 5; // score = score + 5;
score -= 2; // score = score - 2;
score *= 2; // score = score * 2;
score /= 2; // score = score / 2;
score %= 5; // score = score % 5;

Console.WriteLine(score); // 3

score++;
Console.WriteLine(score); // 4
score--;
Console.WriteLine(score); // 3
```

`++` یک واحد اضافه و `--` یک واحد کم می‌کند. فعلاً آن‌ها را مثل مثال بالا در دستور جداگانه بنویس؛ نیازی به ترکیبشان با دستور چاپ یا محاسبه‌های دیگر نیست.

## ۳. مقایسه و عملگرهای منطقی

نتیجهٔ مقایسه یک مقدار `bool`، یعنی `true` یا `false` است.

| عملگر | معنی |
| --- | --- |
| `==` | برابر است؟ |
| `!=` | برابر نیست؟ |
| `>` و `<` | بزرگ‌تر و کوچک‌تر |
| `>=` و `<=` | بزرگ‌تر یا مساوی و کوچک‌تر یا مساوی |
| `&&` | هر دو شرط برقرارند؟ |
| `\|\|` | حداقل یکی از شرط‌ها برقرار است؟ |
| `!` | برعکس کردن نتیجهٔ منطقی |

```csharp
int age = 20;
bool hasTicket = true;

Console.WriteLine(age >= 18);                 // True
Console.WriteLine(age >= 18 && hasTicket);    // True
Console.WriteLine(age < 18 || hasTicket);     // True
Console.WriteLine(!hasTicket);                // False
```

`=` مقدار را قرار می‌دهد و `==` مقایسه می‌کند. برای ترکیب شرط‌ها از پرانتز استفاده کن تا خواندنشان ساده باشد؛ مثلاً `(age >= 18) && hasTicket`.

## ۴. محاسبات آماده با Math

`Math` چند ابزار آماده برای محاسبات در اختیارمان می‌گذارد:

```csharp
Console.WriteLine(Math.Max(12, 19)); // 19
Console.WriteLine(Math.Min(12, 19)); // 12
Console.WriteLine(Math.Abs(-7));     // 7
Console.WriteLine(Math.Sqrt(81));    // 9
Console.WriteLine(Math.Pow(2, 3));   // 8
Console.WriteLine(Math.Round(3.6));  // 4
```

`Max` بزرگ‌ترین، `Min` کوچک‌ترین و `Abs` قدرمطلق را برمی‌گرداند. `Sqrt` جذر و `Pow` توان را حساب می‌کند. فعلاً برای جذر از عددهای غیرمنفی استفاده کن.

`Math.Round` عدد را گرد می‌کند، اما برای ورودی `double` نتیجه همچنان `double` است. در نیمهٔ دقیق، قانون پیش‌فرض آن نزدیک‌ترین عدد زوج است؛ مثلاً `Math.Round(2.5)` برابر `2` و `Math.Round(3.5)` برابر `4` می‌شود.

**تمرین کوتاه:** دو عدد ثابت انتخاب کن؛ بزرگ‌ترین آن‌ها و فاصلهٔ بدون علامتشان را با `Math.Max` و `Math.Abs` نمایش بده.

## ۵. کار مقدماتی با رشته‌ها

### چسباندن متن و ساخت پیام

```csharp
string firstName = "Sara";
string lastName = "Ahmadi";
string fullName = firstName + " " + lastName;

Console.WriteLine(fullName);
Console.WriteLine($"Welcome, {fullName}!");
```

`+` بخش‌های متن را به هم می‌چسباند. در شکل دوم، `$` قبل از متن اجازه می‌دهد مقدار متغیرها را داخل `{}` قرار دهیم؛ به این روش درون‌یابی رشته می‌گویند.

تفاوت متن و عدد را فراموش نکن:

```csharp
Console.WriteLine(2 + 3);       // 5
Console.WriteLine("2" + "3");   // 23
Console.WriteLine("Sum: " + 2 + 3);   // Sum: 23
Console.WriteLine("Sum: " + (2 + 3)); // Sum: 5
```

در خط سوم، ابتدا متن و عدد `2` به هم می‌چسبند و بعد `3` هم به متن اضافه می‌شود.

### طول و تغییر حروف

```csharp
string course = "CSharp";
Console.WriteLine(course.Length);    // 6
Console.WriteLine(course.ToUpper()); // CSHARP
Console.WriteLine(course.ToLower()); // csharp
Console.WriteLine(course);           // CSharp
```

`Length` طول رشته را می‌دهد و پرانتز ندارد. `ToUpper()` و `ToLower()` متن جدیدی با حروف بزرگ یا کوچک برمی‌گردانند؛ مقدار اصلی خودکار عوض نمی‌شود. برای نگه داشتن نتیجه می‌توانیم بنویسیم `course = course.ToUpper();`. بزرگ و کوچک شدن حروف در متن فارسی کاربرد مشابه انگلیسی ندارد.

در مثال‌های سادهٔ این دوره، طول را تعداد حروف و نشانه‌ها در نظر بگیر؛ برخی نمادها مثل ایموجی ممکن است در شمارش `Length` بیش از یک واحد باشند.

## ۶. نویسه‌های ویژه

گاهی خود کوتیشن یا یک خط جدید را داخل متن می‌خواهیم. در رشتهٔ معمولی از `\` برای نوشتن این نشانه‌ها استفاده می‌کنیم.

| نشانه در کد | نتیجه |
| --- | --- |
| `\n` | رفتن به خط جدید |
| `\t` | فاصلهٔ تب؛ مقدار فاصله به محیط نمایش وابسته است |
| `\"` | نمایش دابل‌کوتیشن |
| `\\` | نمایش یک بک‌اسلش |

```csharp
Console.WriteLine("First line\nSecond line");
Console.WriteLine("Name\tScore");
Console.WriteLine("She said: \"Hello!\"");
Console.WriteLine("C:\\Bootcamp\\notes.txt");
```

دستور اول دو خط چاپ می‌کند. خروجی دو دستور آخر:

```text
She said: "Hello!"
C:\Bootcamp\notes.txt
```

**تمرین کوتاه:** نام و شهر را با یک دستور `WriteLine` در دو خط چاپ کن؛ سپس نام دوره را بین دابل‌کوتیشن نشان بده.

## ۷. تصمیم‌گیری با if و else

`if` فقط زمانی بخش داخل `{}` را اجرا می‌کند که شرط درست باشد. `else` مسیر جایگزین است:

```csharp
Console.Write("Enter your score (0 to 20): ");
int score = Convert.ToInt32(Console.ReadLine());

if (score >= 10)
{
    Console.WriteLine("Passed");
}
else
{
    Console.WriteLine("Try again");
}
```

با ورودی `10` پیام `Passed` و با ورودی `9` پیام `Try again` چاپ می‌شود. بعد از پرانتز شرط `;` ننویس؛ آکولادها بدنهٔ شرط را مشخص می‌کنند.

### چند مسیر با else if

```csharp
int score = 17;

if (score < 0 || score > 20)
{
    Console.WriteLine("Out of range");
}
else if (score >= 18)
{
    Console.WriteLine("Excellent");
}
else if (score >= 10)
{
    Console.WriteLine("Passed");
}
else
{
    Console.WriteLine("Try again");
}
```

شرط‌ها از بالا بررسی می‌شوند و فقط اولین مسیر درست اجرا می‌شود. ترتیب مهم است: اگر شرط `score >= 10` را قبل از `score >= 18` بگذاریم، نمرهٔ `19` هم وارد مسیر اول می‌شود. بررسی محدوده، فقط معتبر بودن عدد از نظر نمره را بررسی می‌کند؛ ورودی غیرعددی هنوز در مرحلهٔ تبدیل خطا می‌دهد.

## ۸. انتخاب بین چند حالت با switch

وقتی یک مقدار را با چند حالت مشخص مقایسه می‌کنیم، دستور `switch` می‌تواند از چند `else if` خواناتر باشد. برای نمونه، کاربر یکی از گزینه‌های منو را انتخاب می‌کند و برنامه پیام مناسب را نمایش می‌دهد.

### مثال · منوی سادهٔ دوره

```csharp
Console.WriteLine("1. Course information");
Console.WriteLine("2. Exercises");
Console.WriteLine("3. Contact teacher");
Console.Write("Choose an option: ");
int choice = Convert.ToInt32(Console.ReadLine());

switch (choice)
{
    case 1:
        Console.WriteLine("C# Bootcamp");
        break;
    case 2:
        Console.WriteLine("Practice today's lesson.");
        break;
    case 3:
        Console.WriteLine("Ask your question in class.");
        break;
    default:
        Console.WriteLine("Invalid option");
        break;
}

Console.WriteLine("Menu finished.");
```

با ورودی `2`، بعد از نمایش منو، پیام `Practice today's lesson.` و سپس `Menu finished.` چاپ می‌شود. با ورودی `9`، پیام `Invalid option` و سپس پیام پایان را داریم. مانند مثال‌های قبلی این جلسه، فرض می‌کنیم ورودی عدد صحیح قابل تبدیل است؛ `default` ورودی غیرعددی مثل `hello` را مدیریت نمی‌کند، چون تبدیل قبل از رسیدن به `switch` انجام شده است.

- `switch (choice)` مقدار مورد بررسی را مشخص می‌کند.
- هر `case` یک مقدار مشخص، مثل `1`، را بررسی می‌کند؛ بعد از مقدار `:` می‌آید.
- در این مثال، `break` اجرای بخش انتخاب‌شده را تمام می‌کند و از `switch` بیرون می‌رود؛ برنامه از دستور بعد از آن ادامه دارد. اینجا `break` به معنی بستن کل برنامه نیست. کاربرد آن در حلقه‌ها را جلسهٔ سوم یاد می‌گیریم.
- `default` وقتی اجرا می‌شود که هیچ‌کدام از حالت‌ها برابر نباشند. نوشتن آن اجباری نیست، ولی برای گزینهٔ نامعتبر مفید است؛ بدون آن، اگر حالتی منطبق نباشد، برنامه فقط از `switch` عبور می‌کند.

در این شکل سادهٔ سی‌شارپ، اجرای یک بخش خودکار وارد بدنهٔ بخش بعد نمی‌شود. بخش‌های بالا را با `break` تمام کن و مقدار تکراری برای `case` ننویس. `switch` می‌تواند متن هم بررسی کند؛ اما فعلاً همین مثال عددی کافی است.

**انتخاب ابزار:** برای چند مقدار مشخص مثل گزینهٔ منو، `switch` مناسب است. برای بررسی بازه‌ها و شرط‌های ترکیبی مثل نمرهٔ بین ۰ تا ۲۰، فعلاً از `if / else` که یاد گرفته‌ایم استفاده کن.

**تمرین کوتاه:** گزینهٔ `4` را برای پیام `Review your notes.` اضافه کن. ورودی‌های `1`، `4` و `0` را امتحان کن؛ هر بار فقط یک پیام مربوط به انتخاب و یک پیام پایان باید چاپ شود.

## ۹. حلقهٔ while

حلقه یعنی تکرار یک بخش از کد. `while` **قبل از هر بار اجرا** شرط را بررسی می‌کند:

```csharp
int number = 1;

while (number <= 3)
{
    Console.WriteLine(number);
    number++;
}
```

خروجی:

```text
1
2
3
```

| مرحله | مقدار قبل از بررسی | نتیجهٔ شرط | اتفاق |
| --- | --- | --- | --- |
| اول | ۱ | درست | چاپ ۱ و افزایش به ۲ |
| دوم | ۲ | درست | چاپ ۲ و افزایش به ۳ |
| سوم | ۳ | درست | چاپ ۳ و افزایش به ۴ |
| چهارم | ۴ | نادرست | پایان حلقه |

اگر `number++` حذف شود، مقدار همیشه ۱ می‌ماند و حلقه تمام نمی‌شود. اگر شرط از ابتدا نادرست باشد، بدنه حتی یک بار هم اجرا نمی‌شود.

## ۱۰. حلقهٔ do while

در `do while`، اول بدنه اجرا و سپس شرط بررسی می‌شود؛ پس بدنه **حداقل یک بار** اجرا خواهد شد.

```csharp
int number = 5;

do
{
    Console.WriteLine(number);
    number++;
}
while (number <= 3);
```

با اینکه مقدار اولیه ۵ است، خروجی `5` را داریم. همین مثال با `while (number <= 3)` از ابتدا چیزی چاپ نمی‌کرد. به `;` انتهای `do while` توجه کن.

کاربرد ساده: گرفتن یک عدد تا زمانی که کاربر عدد مثبت وارد کند:

```csharp
int number;

do
{
    Console.Write("Enter a positive integer: ");
    number = Convert.ToInt32(Console.ReadLine());
}
while (number <= 0);

Console.WriteLine($"Accepted: {number}");
```

برای ورودی‌های `-2`، `0` و سپس `4`، درخواست سه بار نمایش داده می‌شود و در پایان `Accepted: 4` چاپ می‌شود. این برنامه همچنان فرض می‌کند ورودی عدد صحیح است.

## ۱۱. حلقهٔ for

وقتی شمارنده و تعداد تکرار مشخص است، `for` معمولاً خواناتر است:

```csharp
for (int number = 1; number <= 5; number++)
{
    Console.WriteLine(number);
}
```

سه بخش داخل پرانتز به‌ترتیب این نقش‌ها را دارند:

1. `int number = 1`: فقط یک بار در شروع اجرا می‌شود.
2. `number <= 5`: قبل از هر دور بررسی می‌شود.
3. `number++`: بعد از پایان بدنهٔ هر دور اجرا می‌شود.

برای شمارش معکوس:

```csharp
for (int number = 5; number >= 1; number--)
{
    Console.WriteLine(number);
}
```

### کدام حلقه را انتخاب کنم؟

| وضعیت | انتخاب معمول |
| --- | --- |
| تعداد تکرار مشخص است | `for` |
| تکرار به یک شرط وابسته است و ممکن است هیچ بار اجرا نشود | `while` |
| بدنه باید حداقل یک بار اجرا شود | `do while` |

## مثال کاربردی · مجموع و میانگین سه نمره

در هر دور یک نمره می‌گیریم و به مجموع اضافه می‌کنیم. همهٔ نمره‌ها در این مثال عدد صحیح معتبر بین ۰ تا ۲۰ هستند.

```csharp
int total = 0;

for (int student = 1; student <= 3; student++)
{
    Console.Write($"Score {student}: ");
    int score = Convert.ToInt32(Console.ReadLine());
    total += score;
}

double average = (double)total / 3;
Console.WriteLine($"Total: {total}");
Console.WriteLine($"Average: {average}");

if (average >= 10)
{
    Console.WriteLine("Average is passing.");
}
else
{
    Console.WriteLine("More practice is needed.");
}
```

با ورودی‌های `12`، `15` و `18`، مجموع `45` و میانگین `15` است. `total` بیرون حلقه تعریف شده تا در هر دور از صفر شروع نشود و بعد از حلقه هم قابل استفاده باشد.

## اشتباه‌های رایج

- اشتباه گرفتن `=` با `==`.
- فراموش کردن تبدیل قبل از تقسیم صحیح.
- فراموش کردن تغییر شمارنده یا نوشتن شرطی که هیچ‌وقت نادرست نمی‌شود.
- گذاشتن `;` بلافاصله بعد از شرط `if`، `while` یا پرانتز `for`.
- فراموش کردن `;` انتهای `do while`.
- جا انداختن `:` یا `break` در بخش‌های دستور `switch`.
- تصور اینکه `default` خطای تبدیل ورودی غیرعددی را برطرف می‌کند.
- استفاده از `<=` به جای `<` بدون بررسی تعداد تکرار.

## تمرین و مرور

۱. **زوج یا فرد:** یک عدد صحیح بگیر و با `%` و `if / else` زوج یا فرد بودنش را نمایش بده. ورودی‌های `0`، `7` و `-4` را بررسی کن. انتظار: زوج، فرد، زوج.

۲. **ماشین‌حساب کوچک:** دو عدد صحیح غیرصفر بگیر و جمع، تفریق، ضرب و تقسیم اعشاری آن‌ها را چاپ کن. برای `7` و `2`، تقسیم باید `3.5` باشد.

۳. **پیام چندخطی:** نام و سن را بگیر و با درون‌یابی رشته و `\n` در یک دستور چاپ نمایش بده.

۴. **اعداد زوج:** با `for` عددهای زوج ۲ تا ۲۰ را چاپ کن. این تمرین را یک بار با افزایش ۲تایی و بار دیگر با شرط داخل حلقه حل کن.

۵. **مجموع:** با `while` مجموع عددهای ۱ تا ۵ را به دست بیاور. انتظار: `15`. مجموع را قبل از حلقه صفر کن.

۶. **تکرار دریافت:** با `do while` نمره بگیر تا عددی در محدودهٔ ۰ تا ۲۰ وارد شود. با `-1`، `21` و `18` آزمایش کن؛ فقط عدد آخر پذیرفته می‌شود. لازم نیست ورودی غیرعددی را مدیریت کنی.

۷. **بزرگ‌ترین و فاصله:** دو عدد بگیر و با `Math` بزرگ‌ترین عدد و قدرمطلق تفاضلشان را نمایش بده. برای `8` و `3`، انتظار `8` و `5` است.

۸. **نام روز:** یک عدد صحیح از ۱ تا ۷ بگیر و با دستور `switch` نام روز را چاپ کن؛ ۱ برای شنبه و ۷ برای جمعه باشد. برای مقدارهای دیگر پیام نامعتبر بده. با `1`، `7` و `8` بررسی کن. فعلاً نیازی به switch expression نیست.

**معیار پایان جلسه:** بتوانی شرط پایان یک حلقه را توضیح بدهی و اجرای آن را برای چند دور روی کاغذ دنبال کنی.

## نکات اضافه · مطالعهٔ بیشتر

### شکل جدیدتر در C# 8 · switch expression

این بخش **اختیاری** است و در کلاس تدریس نشده است. از C# 8، شکل دیگری به نام `switch expression` داریم که از بین چند حالت، **یک مقدار نتیجه** تولید می‌کند. این شکل جای دستور `switch` قبلی را حذف نکرده است؛ هر دو کاربرد دارند.

برای اینکه تفاوت فقط در شکل نوشتن باشد، همان گزینه‌های منوی قبلی را این بار به یک پیام تبدیل می‌کنیم. این مثال را جداگانه اجرا کن:

```csharp
Console.Write("Choose an option (1 to 3): ");
int choice = Convert.ToInt32(Console.ReadLine());

string message = choice switch
{
    1 => "C# Bootcamp",
    2 => "Practice today's lesson.",
    3 => "Ask your question in class.",
    _ => "Invalid option"
};

Console.WriteLine(message);
Console.WriteLine("Menu finished.");
```

با ورودی `2`، مقدار `message` برابر `Practice today's lesson.` می‌شود؛ با `9` برابر `Invalid option` است. نتیجه را بعداً با `WriteLine` نمایش می‌دهیم.

| بخش | معنی |
| --- | --- |
| `choice switch` | مقدار مورد بررسی قبل از کلمهٔ `switch` قرار می‌گیرد |
| `1 => "C# Bootcamp"` | اگر مقدار ۱ بود، این رشته نتیجه باشد |
| `,` | جداکنندهٔ حالت‌ها |
| `_` | حالت باقی‌مانده؛ در این مثال نقش مشابه `default` دارد |
| `};` | پایان عبارت و دستور مقداردهی |

در این شکل `case`، `:` و `break` نمی‌نویسیم. `=>` را فعلاً فقط نشانهٔ «این حالت، این نتیجه» بخوان؛ لازم نیست وارد کاربردهای دیگر آن شویم. حالت `_` را آخر بگذار تا ورودی‌های باقی‌مانده را بپذیرد. اگر هیچ حالتی منطبق نباشد و حالت پوشش‌دهنده‌ای هم نداشته باشیم، هنگام اجرا خطا می‌گیریم؛ پس در این مثال `_` را حذف نکن.

برای اجرای چند دستور در هر مسیر، دستور `switch` معمولی را که در درس اصلی آمده به کار ببر؛ مثال اختیاری فقط یک پیام را انتخاب می‌کند. فعلاً نیازی به الگوهای پیچیده‌تر یا شرط‌های جدید در switch expression نداریم.

**تمرین اختیاری:** تمرین نام روز را با همین شکل بازنویسی کن و نتیجهٔ دو راه‌حل را برای ورودی‌های `1`، `7` و `8` مقایسه کن؛ خروجی‌ها باید یکسان باشند.
