# جلسهٔ اول · اولین گفت‌وگو با برنامه

<div class="lesson-intro">تاریخ برگزاری: <bdi dir="ltr">1405/07/23</bdi><br>در این جلسه یاد می‌گیریم اطلاعات را نمایش دهیم، در متغیر نگه داریم و از کاربر دریافت کنیم.</div>

## هدف‌های جلسه

بعد از مطالعه باید بتوانی تفاوت `Write` و `WriteLine` را توضیح بدهی، برای داده‌ها نوع و نام مناسب انتخاب کنی و یک برنامهٔ ساده برای دریافت و نمایش اطلاعات بنویسی.

### روش اجرای مثال‌ها

یک پروژهٔ Console بساز و هر مثال را **جداگانه** در فایل `Program.cs` اجرا کن. مثال‌ها برای قالب جدید Console نوشته شده‌اند؛ دستورها را مستقیم در فایل قرار بده. اگر پروژهٔ کلاس شما از قبل بخش `Main` دارد، دستورهای مثال را داخل همان بخش بنویس. لازم نیست فعلاً ساختار آن را یاد بگیری.

در همهٔ جلسات، کادرهای کد با برچسب `csharp` ورودی برنامه‌اند و کادرهای `text` خروجی مورد انتظار را نشان می‌دهند. متن انگلیسی داخل مثال‌ها فقط برای ساده‌تر شدن نمایش کنسول است.

## ۱. نمایش خروجی در کنسول

کنسول محیطی متنی برای ارتباط با برنامه است. `Console.WriteLine()` مقدار را نمایش می‌دهد و سپس به خط بعد می‌رود. `Console.Write()` پس از نمایش، در همان خط می‌ماند. بیشتر دستورهای این مثال‌ها با `;` تمام می‌شوند.

```csharp
Console.Write("Hello ");
Console.Write("student!");
Console.WriteLine();
Console.WriteLine("Welcome to C#.");
```

خروجی:

```text
Hello student!
Welcome to C#.
```

فراخوانی `WriteLine()` بدون مقدار، فقط یک خط جدید ایجاد می‌کند. فاصلهٔ بعد از `Hello` را خودمان داخل متن نوشته‌ایم؛ `Write` خودکار فاصله اضافه نمی‌کند.

**تمرین کوتاه:** نام و نام خانوادگی‌ات را با دو دستور `Write` در یک خط چاپ کن. سپس نام شهر را در خط بعد نمایش بده.

## ۲. کامنت؛ یادداشت برای خوانندهٔ کد

کامنت توضیحی است که اجرا نمی‌شود. از آن برای بیان هدف یک بخش یا توضیح یک تصمیم استفاده می‌کنیم.

```csharp
// Display the course name
Console.WriteLine("C# Bootcamp");

/*
This program displays a welcome message.
We will add user input later.
*/
Console.WriteLine("Welcome!");
```

`//` تا انتهای همان خط را به کامنت تبدیل می‌کند. متن بین `/*` و `*/` می‌تواند چند خط داشته باشد. کامنت جای نام‌گذاری خوب را نمی‌گیرد و نباید نتیجهٔ واضح هر خط را تکرار کند.

**تمرین کوتاه:** بالای برنامهٔ قبلی، هدف آن را در یک کامنت بنویس. یک دستور چاپ را موقتاً کامنت کن و تغییر خروجی را ببین.

## ۳. متغیر چیست؟

متغیر را فعلاً مثل یک محل نام‌دار برای نگهداری مقدار تصور کن. موقع تعریف، نوع داده و نام آن را مشخص می‌کنیم.

```csharp
int age = 19;
string firstName = "Sara";

Console.WriteLine(firstName);
Console.WriteLine(age);

age = 20;
Console.WriteLine(age);
```

در `int age = 19`، عبارت `int` نوع، `age` نام و `19` مقدار اولیه است. علامت `=` یعنی «مقدار سمت راست را در متغیر سمت چپ قرار بده»؛ به معنی مقایسه نیست. بعداً می‌توانیم مقدار `age` را عوض کنیم، اما نمی‌توانیم متن را در متغیری با نوع `int` قرار دهیم.

تعریف و مقداردهی می‌توانند جدا باشند؛ متغیر محلی باید قبل از خوانده شدن مقدار داشته باشد:

```csharp
int score;
score = 18;
Console.WriteLine(score);
```

## ۴. نام‌گذاری متغیرها

نام خوب، معنی داده را روشن می‌کند. برای متغیرهای این دوره از نام انگلیسی و روش `camelCase` استفاده می‌کنیم: کلمهٔ اول کوچک است و کلمه‌های بعدی با حرف بزرگ شروع می‌شوند.

| نمونه | توضیح |
| --- | --- |
| `studentName` | روشن و مناسب برای نام دانشجو |
| `totalPrice` | روشن و مناسب برای قیمت کل |
| `x` | قانونی است، ولی معمولاً معنی کافی ندارد |
| `2score` | نامعتبر؛ نام با عدد شروع نمی‌شود |
| `first name` | نامعتبر؛ فاصله مجاز نیست |
| `class` | نامعتبر در این شکل؛ کلمهٔ رزروشدهٔ زبان است |

نام می‌تواند از حرف یا `_` شروع شود و بعد از آن عدد هم داشته باشد. سی‌شارپ به بزرگی و کوچکی حروف حساس است؛ `age` و `Age` دو نام متفاوت‌اند. استفاده از `camelCase` یک قرارداد خوانایی است، نه شرط کامپایل شدن.

**تمرین کوتاه:** برای «تعداد دانشجو»، «قیمت کتاب» و «آیا ثبت‌نام انجام شده؟» نام‌های مناسبی انتخاب کن.

## ۵. نوع داده و اندازهٔ آن

نوع داده تعیین می‌کند چه مقدارهایی را می‌توانیم نگه داریم. اندازه‌های جدول مربوط به خود مقدار هستند؛ برای محاسبهٔ کل حافظهٔ برنامه کافی نیستند. هر بایت برابر ۸ بیت است.

| نوع | اندازه | کاربرد یا محدوده |
| --- | --- | --- |
| `byte` | ۱ بایت | عدد صحیح از ۰ تا ۲۵۵ |
| `short` | ۲ بایت | عدد صحیح از ۳۲٬۷۶۸− تا ۳۲٬۷۶۷ |
| `int` | ۴ بایت | عدد صحیح از ۲٬۱۴۷٬۴۸۳٬۶۴۸− تا ۲٬۱۴۷٬۴۸۳٬۶۴۷ |
| `long` | ۸ بایت | عدد صحیح بزرگ‌تر، حدود ۹٫۲ × ۱۰ به توان ۱۸ در هر جهت |
| `float` | ۴ بایت | عدد اعشاری با حدود ۶ تا ۹ رقم معنادار |
| `double` | ۸ بایت | عدد اعشاری با حدود ۱۵ تا ۱۷ رقم معنادار |
| `decimal` | ۱۶ بایت | حدود ۲۸ تا ۲۹ رقم معنادار؛ مناسب محاسبات پولی |
| `bool` | ۱ بایت برای مقدار | فقط `true` یا `false` |
| `char` | ۲ بایت | یک واحد نویسهٔ UTF-16 مانند `'A'` |
| `string` | ثابت نیست | متن؛ میزان حافظه به طول آن و سربار نگهداری وابسته است |

نیازی به حفظ همهٔ محدوده‌ها نیست. فعلاً برای سن و تعداد از `int`، برای محاسبات اعشاری عمومی از `double` و برای متن از `string` استفاده کن. اندازهٔ بیشتر همیشه به معنی انتخاب بهتر نیست؛ نوع را متناسب با داده انتخاب می‌کنیم.

```csharp
int studentCount = 24;
long population = 8500000000L;
float temperature = 23.5F;
double height = 1.75;
decimal price = 125000.50M;
bool isRegistered = true;
char grade = 'A';
string courseName = "C#";

Console.WriteLine(studentCount);
Console.WriteLine(population);
Console.WriteLine(temperature);
Console.WriteLine(height);
Console.WriteLine(price);
Console.WriteLine(isRegistered);
Console.WriteLine(grade);
Console.WriteLine(courseName);
```

پسوندهای `L`، `F` و `M` نوع مقدار نوشته‌شده را مشخص می‌کنند. مقدار اعشاری بدون پسوند معمولاً `double` است. برای `char` از تک‌کوتیشن و برای `string` از دابل‌کوتیشن استفاده می‌کنیم. همهٔ نمادهای نمایشی، مثل بعضی ایموجی‌ها، در یک `char` جا نمی‌شوند؛ فعلاً از حروف ساده استفاده کن.

> `float` و `double` بعضی اعشار را تقریبی نگه می‌دارند. همچنین شمارهٔ تلفن و کد پستی، با وجود داشتن رقم، معمولاً متن هستند؛ ممکن است با صفر شروع شوند و قرار نیست با آن‌ها جمع و تفریق کنیم.

## ۶. تبدیل نوع ضمنی و صریح

گاهی لازم است مقداری را از یک نوع به نوع دیگر ببریم.

### تبدیل ضمنی؛ بدون نوشتن cast

برای بعضی تبدیل‌ها، زبان اجازه می‌دهد تبدیل خودکار انجام شود:

```csharp
int count = 12;
long largerCount = count;
double countAsDouble = count;

Console.WriteLine(largerCount);   // 12
Console.WriteLine(countAsDouble); // 12
```

این مثال‌ها مجازند، اما نباید قانون «هر نوع با بایت بیشتر همیشه تبدیل ضمنی دارد» را بسازیم. تبدیل ضمنی به قوانین نوع‌ها بستگی دارد؛ مثلاً از `double` به `decimal` تبدیل ضمنی نداریم. بعضی تبدیل‌های ضمنی مانند `long` به `double` هم ممکن است دقت عدد را کم کنند.

### تبدیل صریح؛ با نوشتن cast

با نوشتن نام نوع مقصد داخل پرانتز، تبدیل را صریح درخواست می‌کنیم:

```csharp
double score = 18.9;
int wholeScore = (int)score;
Console.WriteLine(wholeScore); // 18

int negative = (int)(-18.9);
Console.WriteLine(negative); // -18
```

در تبدیل اعشاری به صحیح با cast، قسمت اعشاری حذف می‌شود؛ گرد کردن انجام نمی‌شود. حذف اعشار به سمت صفر است. برای این مثال‌ها عدد باید در محدودهٔ نوع مقصد باشد؛ cast راهی برای جا دادن هر عددی در هر نوعی نیست.

## ۷. تبدیل با Convert

`Convert` روش‌هایی آماده برای تبدیل مقدار دارد. بخش بعد از نقطه نوع مقصد را مشخص می‌کند:

```csharp
int age = Convert.ToInt32("21");
double wholeNumber = Convert.ToDouble("12");
bool isActive = Convert.ToBoolean("true");
string scoreText = Convert.ToString(18);

Console.WriteLine(age);         // 21
Console.WriteLine(wholeNumber); // 12
Console.WriteLine(isActive);    // True
Console.WriteLine(scoreText);   // 18
```

`ToInt32` همان تبدیل به `int` است. متن ورودی باید قابل تبدیل و در محدودهٔ نوع مقصد باشد. مثلاً `Convert.ToInt32("hello")` و `Convert.ToInt32("18.5")` به عدد صحیح تبدیل نمی‌شوند و خطا می‌دهند.

### Convert با cast چه فرقی دارد؟

| نیاز | انتخاب در مثال‌های این جلسه |
| --- | --- |
| تبدیل `int` به `double` | تبدیل ضمنی کافی است |
| حذف قسمت اعشاری یک `double` | استفاده از `(int)` |
| تبدیل متن عدد صحیح به `int` | استفاده از `Convert.ToInt32` |
| گرد کردن یک `double` به `int` | استفاده از `Convert.ToInt32` با توجه به قانون گرد کردن |

```csharp
double value = 7.8;
Console.WriteLine((int)value);           // 7
Console.WriteLine(Convert.ToInt32(value)); // 8

Console.WriteLine(Convert.ToInt32(2.5)); // 2
Console.WriteLine(Convert.ToInt32(3.5)); // 4
```

`Convert.ToInt32` برای مقدار `double` به نزدیک‌ترین عدد صحیح گرد می‌کند؛ در فاصلهٔ دقیقاً برابر، عدد صحیح زوج را انتخاب می‌کند. بنابراین همیشه «نیم به بالا» نیست. این رفتار مربوط به ورودی عددی است؛ متن `"7.8"` با `ToInt32` مستقیم تبدیل نمی‌شود.

نوشتن `(int)"21"` هم معتبر نیست؛ cast در اینجا متن را به عدد تبدیل نمی‌کند.

## ۸. دریافت ورودی از کاربر

`Console.ReadLine()` یک خط از ورودی می‌خواند. کاربر مقدار را می‌نویسد و Enter می‌زند. ورودی ابتدا متن است، حتی اگر فقط رقم وارد شده باشد.

```csharp
Console.Write("Enter your name: ");
string name = Console.ReadLine() ?? "";

Console.Write("Enter your age: ");
int age = Convert.ToInt32(Console.ReadLine());

Console.WriteLine("Name: " + name);
Console.WriteLine("Age: " + age);
```

برای ورودی‌های `Sara` و `20`، نتیجهٔ نهایی این است:

```text
Name: Sara
Age: 20
```

در خط دریافت نام، `?? ""` یعنی اگر هیچ خطی دریافت نشد، متن خالی را قرار بده. فعلاً همین کاربرد کوچک کافی است؛ نیازی به ورود به جزئیات آن نداریم.

در مثال‌های عددی این دوره فرض می‌کنیم کاربر ورودی معتبر وارد می‌کند. برای تمرین از رقم‌های انگلیسی مثل `20` استفاده کن. تبدیل متن اعشاری به تنظیمات منطقه‌ای سیستم وابسته است؛ فعلاً تمرین‌های ورودی را با عدد صحیح انجام بده. رسیدگی کامل به ورودی نامعتبر موضوع جلسه‌های بعدی است.

## مثال کاربردی · کارت معرفی دانشجو

این برنامه فقط از دریافت ورودی، تبدیل نوع و نمایش خروجی استفاده می‌کند:

```csharp
Console.Write("First name: ");
string firstName = Console.ReadLine() ?? "";

Console.Write("City: ");
string city = Console.ReadLine() ?? "";

Console.Write("Age: ");
int age = Convert.ToInt32(Console.ReadLine());

Console.WriteLine("--- Student Card ---");
Console.WriteLine("Name: " + firstName);
Console.WriteLine("City: " + city);
Console.WriteLine("Age: " + age);
```

ابتدا ورودی‌ها دریافت می‌شوند، سپس کارت چاپ می‌شود. عمل `+` در کنار متن، برای چسباندن بخش‌های متن به کار رفته است؛ در جلسهٔ دوم بیشتر بررسی می‌کنیم.

## اشتباه‌های رایج

- جا انداختن `;` یا یکی از کوتیشن‌ها.
- نوشتن `console` به جای `Console`؛ بزرگی و کوچکی حروف مهم است.
- استفاده از متغیر قبل از مقداردهی.
- اشتباه گرفتن متن `"20"` با عدد `20`.
- تصور اینکه cast عدد اعشاری را گرد می‌کند.
- انتخاب `int` برای شمارهٔ تلفنی که با صفر شروع می‌شود.

## تمرین و مرور

۱. **شناسنامهٔ دوره:** نام دوره، نام مدرس و تعداد دانشجوها را در متغیرهای مناسب نگه دار و در سه خط نمایش بده.

۲. **انتخاب نوع:** برای سن، قد، قیمت کالا، حرف سطح زبان، وضعیت پرداخت و شمارهٔ تلفن نوع مناسب پیشنهاد بده و دلیل کوتاهی بنویس.

۳. **پیش‌بینی خروجی:** بدون اجرا، نتیجهٔ `(int)12.9`، `Convert.ToInt32(12.9)` و `Convert.ToInt32(12.5)` را بنویس. سپس اجرا کن. انتظار: به‌ترتیب `12`، `13` و `12`.

۴. **اطلاعات کتاب:** نام کتاب، نام نویسنده و تعداد صفحه را از کاربر بگیر و یک کارت معرفی چاپ کن. برای تعداد صفحه از `int` استفاده کن.

۵. **اصلاح کد:** خطاهای زیر را پیدا و اصلاح کن. فعلاً نیازی به شرط یا حلقه نیست.

```csharp
// Incorrect code — fix before running
int 2age = "20";
string city = 'Tehran';
console.WriteLine(city)
```

**معیار پایان جلسه:** بتوانی یک ورودی متنی و یک ورودی عددی بگیری، در متغیر مناسب نگه داری و با برچسب روشن نمایش بدهی.
